# Direct Tyres Solutions — Site Overview

Marketing/lead-gen website for a mobile tyre-fitting business (Rapid Response Tyres / Direct Tyre Solutions) covering Manchester, Oldham, Rochdale and surrounding North West England areas.

## Stack

- Next.js 16 (App Router), React 19, TypeScript (strict)
- Tailwind CSS v4 — theme tokens defined via `@theme` in `src/app/globals.css` (colors: `primary`, `secondary`, `accent`, `surface`, `text-main`, `text-muted`, etc. — use these utility classes, not raw hex)
- Fonts: Inter (`--font-sans`), Chivo (`--font-heading`), JetBrains Mono (`--font-mono`), loaded via `next/font/google` in `src/app/layout.tsx`
- ESLint via `eslint-config-next`
- No test suite, no database, no auth — this is a static/marketing site with one API route

## Structure

- `src/app/page.tsx` — the live homepage, currently renders `HomePage2` (the "home2" design variant)
- `src/app/home-1/`, `src/app/home-3/` — alternate homepage designs (`HomePage` and `HomePage3`), not linked from nav; likely kept for comparison/rollback
- `src/app/mobile-tyre-fitting-<area>/page.tsx` — one route per service area (Oldham, Rochdale, Manchester, Chorlton, Didsbury, etc.), each a thin wrapper rendering a matching component from `src/components/locations/`
- `src/components/` — shared/home-1 components (Hero, Services, Pricing, Gallery, QuoteContact, etc.)
- `src/components/home2/` — components used by the live homepage (`HomePage2`, `Header2`, `Hero2`, `Footer2`, etc.) — this is the design system actually in use
- `src/components/home3/` — components for the unused `home-3` variant
- `src/components/locations/` — one page component per service-area route, plus shared `LocationHeader`, `LocationFooter`, `ScrollDeck`
- `src/lib/site-data.ts`, `site-data-v2.ts`, `site-data3.ts` — copy/content data for the three homepage variants respectively
- `src/lib/locations-data.ts` — canonical list of service areas (`slug`, `label`, `href`) used for nav/footer links; add new areas here first when adding a new location page
- `src/app/api/quote/route.ts` — POST endpoint backing the quote/contact form; currently only validates input and `console.log`s it (see TODO in the file — no email/CRM is wired up yet)

## Conventions

- New location pages: add an entry to `locations-data.ts`, create `src/components/locations/<Area>Page.tsx`, and a matching `src/app/mobile-tyre-fitting-<slug>/page.tsx` that just renders it — follow the pattern of existing area pages exactly.
- Use the Tailwind theme tokens from `globals.css` for colors/fonts rather than introducing new raw values.
- Path alias `@/*` maps to `src/*`.
- No `node_modules` is installed in this environment by default — run `npm install` before `npm run dev`/`npm run build`/`npm run lint`.
